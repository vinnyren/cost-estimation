# v2.4 反算路径视觉升级 — Design Spec

> **Status:** Drafted（user 选 "视觉升级 reverse 路径到 v2.2 token"）
> **Branch:** `v2.4-reverse-visual`（off v2.3-closure `0d2a038`）
> **Date:** 2026-05-11

## 1. 目标

把 `ResultView.vue` 的 **reverse 分支**视觉升级到 v2.2 design import token 体系，与 forward 分支保持一致。**纯前端 + 纯视觉**：不动算法、不动 schema、不动 API。

**v2.2 升级范围只覆盖 forward 路径**（加了 ResultTrio + PipelineGrid + CostBar + ComplianceCard），reverse 仍用 v1.x 的 ResultCard + 旧 fieldset 样式。本 spec 闭环这个不一致。

## 2. 当前差距

| 区域 | 现状（v2.3） | 目标（v2.4） |
|---|---|---|
| **反算输入卡片** | `<fieldset class="card reverse-card">` 旧样式，单列 | v2.2 `<div class="card">` + 4 列 `.field-row` grid |
| **三档 FP 卡片** | `<ResultCard>` × 3 旧组件 | `<ResultTrio>` 单组件 (v2.2 P4 加的) |
| **Page header** | "重新计算" / "下载报告" 按钮在 footer 的 dl-bar | 移到 page-header right (与 forward 一致) |
| **背景** | 平 `.bg` | `.hero-bg` accent gradient (与 forward 一致) |
| **section 文案** | "评估结果（反向）" | "反向反推 · {项目名}" (按 design import) |

## 3. Scope decisions

| ID | 决策 | 结果 |
|---|---|---|
| D1 | Scope | 纯视觉重做 reverse 路径；算法/schema/API 不动 |
| D2 | "可用预算" 字段 | computed disabled 显示 `target - other_cost`（user 不可编辑）|
| D3 | "α 开发占比" 字段 | 显示但 disabled（已在 Wizard 设定，本视图只展示）|
| D4 | ResultTrio extras 内容 | 简化为 2 行：未调整规模 US + ≈ N 个模块（不加 design import 的 mock "反算造价/误差"，避免数据来源不明的字段）|
| D5 | ComplianceCard | reverse 模式不加（YAGNI；ResultTrio + Allocator 一致性 banner 已覆盖）|
| D6 | Reverse FP 卡片 label 文案 | "乐观 · 最大可承载" / "中位 · 推荐采纳" / "保守 · 最少可保证"（与 design import 一致，区别于 forward 的"行业最高效率/CSBMK 行业基准/含返工"）|

### 6.2 三档 FP 卡片用 ResultTrio

定义 `reverseTiers` computed：

```ts
const reverseTiers = computed(() => {
  if (!reverseResult.value) return [];
  const r = reverseResult.value;
  return (["P10", "P50", "P90"] as const).map((k) => ({
    key: k,
    label: k === "P10" ? "乐观 · 最大可承载"
         : k === "P50" ? "中位 · 推荐采纳"
         : "保守 · 最少可保证",
    cost: 0,  // unused in unit=fp mode
    fp: r.scale_adjusted_bands[k],
    recommended: r.recommended_band === k,
    unit: "fp" as const,
    extras: [
      ["未调整规模 US", `${r.scale_unadjusted_bands[k].toFixed(2)} FP`],
    ] as Array<[string, string]>,
  }));
});
```

Template:

```vue
<ResultTrio v-if="reverseResult" :tiers="reverseTiers" />
```

注：`ResultTrio` 在 v2.2 P4 已支持 `unit: "fp"` 分支（显示 FP 单位 + "≈ N 个模块" 副文本），无需改动该组件。

### 7.2 e2e `v2.4-reverse-visual.spec.ts`

```ts
import { test, expect, request } from "@playwright/test";

const BASE_URL = "http://127.0.0.1:8788";
const AUTH_TOKEN = "e2e-token";

async function createReverseProject(): Promise<string> {
  const ctx = await request.newContext({
    baseURL: BASE_URL,
    extraHTTPHeaders: { "X-Auth-Token": AUTH_TOKEN, "content-type": "application/json", Origin: BASE_URL },
  });
  const r = await ctx.post("/api/projects", {
    data: {
      name: `Reverse Visual E2E ${Date.now()}`,
      project_type: "dev_only", phase: "bidding",
      city: "北京", industry: "电子政务",
      mode: "reverse", basis_data_ver: "CSBMK-202510",
      target_cost: 1500000, other_cost: 60000,
    },
  });
  return (await r.json()).data?.id ?? (await r.json()).id;
}

test("reverse view 4 列 grid + ResultTrio + AllocatorPanel 都在", async ({ page }) => {
  const pid = await createReverseProject();
  await page.goto(`/projects/${pid}/result`);
  await page.waitForLoadState("networkidle");

  // page header
  await expect(page.locator(".page-title", { hasText: "反向反推" })).toBeVisible();

  // 4 列 grid 输入
  const grid = page.locator(".page .card").first();
  await expect(grid.locator("label.field-label", { hasText: "目标总造价" })).toBeVisible();
  await expect(grid.locator("label.field-label", { hasText: "其他费用" })).toBeVisible();
  await expect(grid.locator("label.field-label", { hasText: "可用预算" })).toBeVisible();
  await expect(grid.locator("label.field-label", { hasText: "α 开发占比" })).toBeVisible();

  // 反算按钮
  await page.locator(".btn-primary", { hasText: "反算" }).click();

  // ResultTrio 3 卡片渲染
  await expect(page.locator(".result-trio .result-card")).toHaveCount(3);
  await expect(page.locator(".result-card.recommended")).toBeVisible();
  await expect(page.locator(".result-card")).toContainText("FP");  // unit

  // AllocatorPanel 仍在
  await expect(page.locator(".allocator-panel")).toBeVisible();
});
```
